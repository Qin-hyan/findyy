## 本轮新增（验收工作台）

- `/workbench` 单页：运行状态、设备采集、检测结果、轨迹关联、找物查询、六项验收总览、操作引导。
- 设备探测与会话内真机切换：页面填写 IP → 检查连接 → 使用此设备采集（不写用户配置文件，重启恢复）。
- 每帧记录 `source_kind`（esp32/replay/upload）与 `detect_ms/embed_ms/process_ms/detect_error`，界面展示真实耗时与失败原因。
- 验收运行与事件证据：`acceptance_runs` / `acceptance_events`；六项状态由本机事件计算，没有操作即 `NOT VERIFIED`。
- 回放运行明确标记 `simulated=true`，replay 数据不会让真机项通过；导出 JSON 不含图像、设备地址与绝对路径已脱敏。
- 抓拍等待提示真实秒数，超时 240 秒，不把 OWLv2 CPU 6–11 秒的慢推理误判为失败。

- 演示：6 帧 29 次检测，23 matched / 1 ambiguous / 5 new。
- 自动化：`pytest` **89 passed、0 failed**（原 75 项 + 新增 14 项工作台/来源/验收测试）。
- 浏览器：历史演示 12/12、真机 7/7；**本轮工作台 replay 演示 38/38**，无失败请求、无未预期 console error（仅负向探测预期 400）。
- 工作台六项（replay 演示）：设备连接 `NOT VERIFIED`（演示模式不验证真机），真实抓拍/检测/存储/轨迹关联/查询 `PASS`，总体 `NOT VERIFIED` 且 `simulated=true`。
- 实测单帧 CPU：OWLv2 6.24–10.62s（本轮 replay 检测 5.36–5.60s 属于同量级），DINOv2 5 图 0.53s。
- 隔离验证：新代码在独立 8766 实例、独立 DB/图像目录、复制回放帧上验证；原 8765 服务、原数据库、原回放帧未被重启或消耗。
