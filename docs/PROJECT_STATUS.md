# Findy 项目状态（2026-10-28）

## 一句话

Findy MVP 已在本机跑通「摄像头抓拍 → 开放词表检测 → 同一实物跨帧关联 → 本地历史存储 → 中文自然语言查询 → 带证据的界面展示」闭环，自动化与浏览器验收通过；**真实 ESP32 硬件端到端与真实场景精度尚未验证**。

## 已验证事项（有证据）

- 6 帧演示序列：29 次检测、23 次自动关联、1 次灰区待确认、5 次新物品建档；手机/笔记本/鼠标各 6/6 帧关联到同一轨迹。
- 73 个自动化测试通过（`pytest`）：关联打分与三态、中文意图解析、区域判定、SQLite 幂等/合并、API、ESP32 适配器（mock 固件服务）、无效上传/404/检测失败等异常路径。
- Chrome + Playwright 真实交互 12 项检查全部通过（状态栏、物品库、时间线、三类查询、抓拍、检测框、历史回看）。
- 时间未同步场景：接口返回 `null`、界面与查询答案明确标注，无伪造时间。
- 实测单帧 CPU：OWLv2 检测 6.24–10.62s（均值 7.83s，3 次），DINOv2 5 个裁剪图 0.53s，模型加载 13.96s / 0.40s。
