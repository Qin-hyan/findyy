操作引导

从设备通电到导出验收证据
  1. 设备通电（ESP32-S3-EYE），用 USB 连接电脑查看串口日志，确认出现 Web UI ready: http://<设备IP>/。
  2. 确认电脑与设备连接在同一 Wi-Fi 网络。
  3. 获取设备 IP：看串口日志，或登录路由器管理页查看设备列表。
  4. 在上方“设备地址”输入 http://<设备IP>，点击“检查连接”。
  5. 连接成功后点击“使用此设备采集（仅本次会话）”，再点击“立即抓拍”。
  6. 移动物品后再次抓拍，观察“轨迹关联”中的跨帧时间线与灰区候选。
  7. 用“找物查询”提问，核验中文回答、证据图片与关联分。
  8. 结束本轮验收并导出证据 JSON 存档。

长期配置请写入 config/findy.local.yaml（示例见右），重启服务后生效。

# config/findy.local.yaml
app:
  tz: Asia/Shanghai

capture:
  source: esp32          # esp32 | replay
  interval_seconds: 60
  esp32:
    base_url: http://<设备IP>
    timeout_seconds: 20

# 也可用环境变量 FINDY_ESP32_URL 覆盖
